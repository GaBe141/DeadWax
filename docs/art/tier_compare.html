What the screen actually draws at 48px (zoomed 4×)

Rendered at real gameplay height, then blown up nearest-neighbor so you can see the pixels the GPU commits. Left = dense (muddy, low contrast with the floor). Right = readable (clean, high contrast).
So the two-tier split isn't a compromise — it's using each style where it wins: full density where the player stops to look (portraits, cutaways, cutscenes, shops, the map) and bold readability where the player is fighting for their life (gameplay sprites). Same art direction, same hand, same grime vocabulary — just dialed for the distance. If after seeing this you still want full density in combat too, we can — but I'd want to prove one enemy stays readable against a finished background before we commit the roster to it.
